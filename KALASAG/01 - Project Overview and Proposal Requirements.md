# Project Overview and Proposal Requirements

## Project

- Name: Kalasag: An Emergency Survival and Disaster Readiness App
- Field: Public Safety / Disaster Risk Reduction and Management
- Target: Android
- Intended users: Individuals and households in disaster-prone communities
- Related goals: SDG 11 and SDG 13

## Original proposal baseline

The proposal requires an authenticated application with an emergency profile, current weather dashboard, disaster alerts and interactive weather map, offline preparedness guides, custom emergency contacts with controlled dialing, flashlight and whistle tools, and an online AI survival assistant with an offline fallback.

The source code is the authority for current implementation status. The proposal is the baseline for identifying gaps.

## Safety principles

- Never describe demo alert data as live or official.
- Never place a call without the user confirming in the native dialer.
- Keep offline guidance distinct from current warnings.
- Do not embed private AI, backend, or signing credentials in the app.
- Do not claim device behavior without physical-device evidence.
